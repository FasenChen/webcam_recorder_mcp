# 实现与验收

目标：通过标准 stdio MCP 控制 Windows 摄像头，为测试运行留下可复盘的视频。

范围：单摄像头、单个活动录制；设备/能力查询、开始、状态、停止；FFmpeg 输出分片 MP4；独立配置与 Git 仓库。不增加直播、云上传或视频识别。

录制开始必须收到实际视频帧；停止必须等待 FFmpeg 退出并由 ffprobe 校验视频。记录 UUID、UTC 起止时间、帧数、时长、文件位置和失败原因；视频、日志和元数据只保存在忽略的运行目录中。重复停止可读取已完成结果，禁止覆盖已有录制。会话退出应停止录制，Windows Job Object 在服务被强制结束时回收 FFmpeg，分片 MP4 尽量保留已写入内容。

宿主接入：后端自动控制录制，不把控制工具交给任务模型；每次 TestRun 录一段，结束/异常/取消后收尾。视频作为运行级 Artifact，原截图保持任务级；新增数据库迁移保留历史数据。使用文件响应支持 Range，报告播放/下载视频，HTML 导出引用同目录视频文件，不内嵌大文件。

验收：配置及路径校验；录制互斥、启动失败、启动超时、重复停止、异常退出、会话关闭；真实 stdio 握手/工具发现；C920 实际录制并 ffprobe/解码核对；宿主正常/取消/失败流程、视频归属和 Range；前后端测试、类型和生成产物检查。真实硬件结果与离线测试分开记录。
